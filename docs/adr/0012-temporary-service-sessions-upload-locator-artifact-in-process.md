# Temporary Service Sessions detach before the Locator Artifact upload

tsvc's Chrome, Motrix, and cloudflared are children of `session.mjs`. GitHub ends that process group when a `run:` step returns, so the session is started with `setsid` and kept across the following YAML `actions/upload-artifact` step. After readiness, `session.mjs` writes `session-deck-output.md`; the job uploads `session-deck-locators` the same way Debug Sessions do. In-process `@actions/artifact` from bash cannot upload: `run:` does not receive `ACTIONS_RUNTIME_TOKEN`. Locators are required; Sensitive Facts stay optional. Session Deck still falls back to the check-run summary for runs that have not migrated. Job logs are not the Observer (ADR-0013).
