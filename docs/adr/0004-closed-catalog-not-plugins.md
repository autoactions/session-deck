# Attach a session project by naming its GitHub repo here; it does not plug itself in

This Worker manages a session project when this plane is given that project's GitHub repository (token, `owner/repo`, ref). A plugin, manifest, or SDK in the session repo was rejected: those repos must not take on this plane's nouns, and Temporary Service Sessions already forbid a shared gateway and manifest DSL. Which workflows can start is observed from GitHub (ADR-0007), not declared as a plugin.
